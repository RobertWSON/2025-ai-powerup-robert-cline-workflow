# 🪞 Learning Reflection Workflow

> **Purpose:** Purpose: This heading sets context (reason) for when to use learning and reflection workflow. The brain 🧠 emoji symbol represents thinking, understanding and processing what you learnt.
### 🧠 Context

This workflow can be used by you (a user) after finishing a coding task, debugging session, testing or exploring something with AI.
The aim is to record what you learnt, not just what you did.

---

> **Purpose:** This heading defines the sequence of actions a user should follow during AI-assisted debugging. The steps 🪜 emoji symbol represents moving through the process one stage at a time.
### 🪜 Steps

> **Note:** Sub-headings inside this section are ordered list step items, each containing a list of user actions.
1. **Summarize what you worked on** 
   > **Purpose:** These actions give AI a clear understanding of the task or problem you worked on.                                 
   - Briefly describe the task or problem you tackled.
   > **Note:** This action label uses a block quote message as an example for reflection on why a question was asked.
   - Example: 
      > “Investigated why `assert` is used in Python tests to verify that the correct title appears in the todo app.”

2. **Capture AI interactions**
   > **Purpose:** These actions help AI understand context (content and structure) for your conversation. 
   - What did you ask the AI?
   - How did the AI respond?
   - What parts were most useful or surprising?

3. **Identify key learning**
   > **Purpose:** These actions show AI what you learnt during the session, helping reinforce concepts and guide future explanations.
   - What did you understand better after this session?
   > **Note:** This action label uses a block quote message as an example for knowledge gained from learning.
   - Example: 
      > “Realised that `assert` statements in Python tests automatically check expected behaviour, and if an assertion fails, it highlights exactly which part of the code is broken.”   

4. **Note any recurring patterns**
   > **Purpose:** These actions help you recognise recurring mistakes or habits in your workflow, which can later be automated or turned into a checklist.   
   - Did you see a mistake or habit repeating?
   - Could it be automated or turned into a checklist?

5. **Next steps**
   > **Purpose:** These actions tell AI what you want to improve next, helping guide future debugging or learning sessions.
   - One improvement you’ll make in your next session.
   > **Note:** This action label uses a block quote message as an example for a question to ask AI during learning.  
   - Example: 
      > “Ask the AI for code reasoning *before* applying fixes.”
