
# 🪞 Learning Reflection Workflow

### 🧠 Context
Use this workflow after finishing a coding task, debugging session, or AI-assisted experiment.  
The aim is to record what you *learned*, not just what you *did*.

---

### 🪜 Steps

1. **Summarize what you worked on**
   - Briefly describe the task or problem you tackled.
   - Example: “Investigated why `assert` is used in Python tests to verify that the correct title appears in the todo app.”

2. **Capture AI interactions**
   - What did you ask the AI?
   - How did the AI respond?
   - What parts were most useful or surprising?

3. **Identify key learning**
   - What did you understand better after this session?
   - Example: “Realized that `assert` statements in Python tests automatically check expected behavior, and if an assertion fails, it highlights exactly which part of the code is broken.”   

4. **Note any recurring patterns**
   - Did you see a mistake or habit repeating?
   - Could it be automated or turned into a checklist?

5. **Next steps**
   - One improvement you’ll make in your next session.
   - Example: “Ask the AI for code reasoning *before* applying fixes.”

---

### ✅ Outcome
A short, meaningful record of your coding growth — helping you refine your agentic workflow over time and build awareness of how you collaborate with AI.
